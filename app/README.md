# DegenWild — web app

React + Vite frontend for the `degenwild` Anchor program, built on the red/black design from
`C:\degenwild-localhost`. It uses `@solana/kit` 8 and connects wallets through Wallet Standard
(Phantom, Solflare, Backpack…). Transactions are v1, with an automatic fallback to v0 for wallets
that can't sign v1 yet.

What the site does on-chain:

| UI | Instruction |
|---|---|
| Create coinflip (side + 0.05–10 SOL) | `create_battle` (stake goes into the battle PDA escrow) |
| Join (opposite side, same stake) | `join_battle` → ORAO `request_v2` CPI |
| Cancel (your open battle) | `cancel_battle` |
| Claim win / Settle (once ORAO fulfils) | `settle_battle` (winner gets pot − 3.5%, fee to treasury) |
| Refund both (ORAO silent for 750 slots) | `refund_expired_battle` |

The lobby reloads every 5 s from `getProgramAccounts`, and the site reads ORAO's randomness account
to show the result before anyone settles.

## Run

```bash
npm install
npm run dev            # devnet (default)
```

Environment variables: `VITE_CLUSTER` (`devnet` | `localnet` | `mainnet`), `VITE_RPC_URL`,
`VITE_WALLET_CHAIN`. The public devnet RPC rate-limits `getProgramAccounts`, so use a dedicated RPC
URL for anything beyond testing.

### Before devnet works

1. Deploy the program: `anchor build && solana program deploy --program-id target/deploy/degenwild-keypair.json target/deploy/degenwild.so -u devnet`
2. From the `PLATFORM_ADMIN` wallet (`4VUJ…fx7b`), call `initialize_platform_config`. Until this
   runs, battles can be created and joined but not settled.

## Local fork (no devnet SOL needed)

```bash
surfpool start --network devnet --no-deploy --ci          # forks devnet, clones ORAO on demand
solana program deploy --program-id ../target/deploy/degenwild-keypair.json ../target/deploy/degenwild.so -u localhost
npm run e2e:local                                         # 14 end-to-end checks through src/chain.ts
npx tsx scripts/seed-local.ts <yourWallet>                # open battles + 100 SOL for you
VITE_CLUSTER=localnet VITE_WALLET_CHAIN=solana:devnet npm run dev
```

ORAO's oracle doesn't run on a local fork, so battles you join there stay "Flipping…" until the
refund timeout. The e2e script fakes fulfilment with a Surfpool cheatcode, and
`npx tsx scripts/fulfill-local.mts <battle> heads|tails` does the same for a battle you joined in the UI.

## Regenerating the program client

`src/generated/` is generated by Codama from `../target/idl/degenwild.json`. After changing the
program, run `anchor build && npm run codegen`.
